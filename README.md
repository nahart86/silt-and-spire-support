# Silt & Spire support site

A dependency-free static support and marketing site for Silt & Spire. The pages are plain HTML and shared CSS; no build step, JavaScript, tracking, or remote assets are required.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static file server. Keep `styles.css` beside all three HTML pages.

## Pages

- `index.html` — product introduction and CSS-built sand illustrations
- `support.html` — gameplay, accessibility, saved work, and release-status FAQ
- `privacy.html` — app and support-site privacy information

The app is presented as prelaunch until App Store approval and public availability are verified. Add a real App Store link only after checking it resolves to the released listing. The product illustrations are CSS artwork and can be replaced with actual screenshots when available; no image placeholders use broken paths.
